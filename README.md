# AP World History Practice

An offline iPad app for AP World History: Modern. It has 954 AP-style questions across all nine units, with an explanation for every answer choice. It includes 45 mock quizzes (5 per unit), topic drills, a mixed mock weighted like the exam, practice and timed exam modes, and saved progress.

**Open it:** https://eklavya666i.github.io/ap/

## Put it on an iPad

1. Open the link in Safari.
2. Tap Share (or ••• and then Share), then **Add to Home Screen**, then **Add**.
3. Open it once from the new icon while online. After that it works offline.

Progress is saved on each device, inside the app. Deleting the icon deletes that device's progress.

## Updating

Changing any file here republishes the site. Installed copies pick up the new version the next time they open online.
